# 第三方许可证清单

| ----------------------------------------------- | --------------- | ------------ | --------------------------------------------- |
| React / React DOM                               | peer dependency | MIT          | 组件运行时；不会打入组件库产物                |
| Radix UI                                        | 1.6.7           | MIT          | Dialog、Dropdown、ScrollArea 等无障碍行为基础 |
| Lucide React                                    | 0.577.0         | ISC          | 与 Console Neo 一致的通用图标来源             |
| TanStack React Table                            | 8.21.3          | MIT          | QueryDataTable 的领域中立表格模型             |
| Sonner                                          | 2.0.7           | MIT          | 与 Console Neo 一致的 Toast 行为和动画基础    |
| Geist Variable                                  | 5.2.8           | OFL-1.1      | 默认等宽/辅助字体资源                         |
| Outfit Variable                                 | 5.2.8           | OFL-1.1      | Console Neo 默认界面字体资源                  |
| Vite / Vitest / Storybook / ESLint / TypeScript | 开发依赖        | 各项目许可证 | 构建、测试、文档和静态检查，不进入运行时产物  |
| Playwright                                      | 1.62.0          | Apache-2.0   | 本地视觉回归与浏览器验证                      |
| Pixelmatch                                      | 7.2.0           | ISC          | 截图像素差异计算                              |
| PNGJS                                           | 7.0.0           | MIT          | 视觉回归 PNG 读写                             |

EaseCation Logo、商标、Console Neo 私有插画及无法确认授权的业务资产不进入公开 npm 包。发布前仍需以 `pnpm-lock.yaml` 和最终产物生成完整的软件物料清单并进行人工许可证复核。
